# ספק · מודל הנתונים והמקורות (R-75) — עיצוב מאושר

**סטטוס:** ‏**אושר על-ידי הבעלים בשיחה, 2026-08-03.** מסמך זה הוא הצורה הכתובה של מה שאושר, לא הצעה.
**מקור:** ‏R-75/R-76 · הערות הבעלים R-79 (94°C) · R-80 (טריגרים) · R-81 (תזונה) · הקורפוס R-77.
**כלל שולט:** ‏§4 — **תוכנית לא מוותרת על דרישה מספק מאושר.** כל ויתור עולה לבעלים בשיחה, לא במסמך.

## 0 · האבחנה, במספרים — למה זה קיים

הבעלים: *"נעשו יותר מדי שינויים על שינויים, טבלת המצבים אינה סופית, ולכן תמיד יימצא מקרה שאינו נתמך."*
המדידה מאשרת, ומצביעה על שורש **אחד**:

```
193 שורות · צורת-שורה שטוחה אחת לכל הפריטים
 47 שורות ללא `safe` כלל     → ג'רקי · בילטונג · בייקון · סלמי · צ'וריזו (בטיחות בריפוי, לא בחום)
 27 שורות עם `safe = 0`      → ירקות ופירות ("לא רלוונטי", מקודד בתוך מרחב-הערכים של המנגנון)
 36 שורות עם `tgt < safe`    → 28% — סו-ויד תקין שנראה כהפרה, כי `safe` הוא מספר ולא עקומה
127/130 שורות `wrap = "לא"`  → שדה מת; העטיפה האמיתית חיה כפרוזה ב-`somid`
 92 ערכים שונים ל-`mid` · 73 ל-`somid` · 25 ל-`sear` (לשדה שנראה כמו כן/לא)
```

**ההוכחה החיה (R-82, 3.8.26):** ‏`safe` מצפין שלושה מצבים, שום דבר בקוד אינו אומר זאת, ולכן **כל צרכן
גזר לעצמו — ולכן גזר אחרת**. נתיב הקול תוקן ב-R-69; שני נתיבי השאלות נשאו `${c.safe||63}` והציגו
**63°C ל-27 שורות ירקות**, בתג ⚡מקומי, כערך משלנו. **אין מקום שבו שתי הפרשנויות נפגשות וסותרות** —
הן פשוט רצות בנתיבים שונים. זה לא ניתן לתיקון בטלאי; זה תיקון של המבנה.

  name:      { he, en }

## 2 · בלוקי הבטיחות — 0..n, והיעדר בלוק הוא האמירה

```yaml
safety:
  - kind: thermal | cure | drying | fermentation | aging | parasite
    …פרמטרים לפי הסוג…
    source_id: <מצביע לקורפוס>
```

| פריט | בלוקים |
|---|---|
| בריסקט | `[thermal]` |
| בייקון | `[cure, thermal]` |
| סלמי מותסס | `[cure, fermentation, drying]` |
| גבינת חלב גולמי | `[aging]` |
| דג נא | `[parasite]` |
| **תירס** | `[]` |

**‏`safety: []` הוא התשובה, לא חור.** ‏0 הוא טמפרטורה לגיטימית, ולכן "לא רלוונטי" **אינו יכול** להיות
מקודד בתוך מרחב-הערכים של המנגנון — הוא חייב לשבת מחוץ לו. **‏R-82 לא יכול היה להיוולד כאן.**

### 2.1 · `thermal` — עקומה, לא מספר

```yaml
kind: thermal
instant_c: 63                 # המספר הקלאסי — נשאר, כמקרה קצה של העקומה
curve:                        # אופציונלי; קיים כשיש מקור לזוגות זמן-טמפרטורה
  - { c: 54, hold_min: 90 }
  - { c: 57, hold_min: 35 }
  - { c: 60, hold_min: 12 }
  - { c: 63, hold_min: 0 }
basis:      thickness | fat_pct | null      # לפי מה העקומה משתנה
basis_ref:  { mm: 40 } | { fat_pct: 12 }    # נקודת הייחוס של העקומה שנשמרה
source_id:  15                              # Baldwin · 2 = FSIS App A · 1 = Food Code
```

**‏36 השורות שבהן `tgt < safe` מפסיקות להיות חריגה.** פיקאניה ב-54°C יושבת **על העקומה**, והאפליקציה
אומרת *למה* — "54°C למשך 90 דקות" — במקום להיראות כהפרה.
מקורות: `basis:'thickness'` ← ‏Baldwin (#15) · `basis:'fat_pct'` ← ‏FSIS Appendix A (#2, 91 שורות,
כולל **פיצול עוף/הודו**) · הסולם הרגעי ← ‏Food Code (#1).

## 3 · יעד המרקם — נפרד לחלוטין מהבטיחות

```yaml
texture:
  target_c:  95
  doneness:  { … סולם מידות, כשקיים … }
  source_id: null
  provenance: craft            # ⚠️ מלאכה, ללא מקור ראשוני
```

הפרדה קריטית וכבר שילמנו עליה: ‏`app.js:4751` מגיש `tgt` כאילו הוא רצפת בטיחות. במבנה החדש **אי-אפשר** —
טיפוסים שונים, בלוקים שונים.

### 3.1 · ‏R-79 — הכרעת הבעלים על 94°C ‏(3.8.26)

**‏94°C לבריסקט נשאר.** ‏`source_id: null`, ‏`provenance: 'craft'`.
הנימוק שנאמר בשיחה: זה המספר שהמוצר בנוי סביבו, ושינויו משנה את המנה.
**הסכימה מחייבת את הדגל** — ערך ללא מקור חייב לשאת `provenance: craft` ולא יכול להתחזות למאומת.
אותה תבנית חלה על שקדי עגל ועל כל `tgt` אחר ללא מקור. **הצד השני נרשם ולא נמחק:** ‏Modernist Cuisine
אומר 57°C ל-48 שעות, ו-Tornberg 2005 (peer-reviewed) מספק מנגנון קולגן 53–63°C **שאינו מגיע** עד
טענת הג'לטיניזציה ב-90°C+.

### 3.2 · ‏R-78 — הכרעת הבעלים על Modernist ‏(3.8.26)

**לא נרכוש את הספר. ויתור מוצהר.** ‏#17 נשאר `🔴 שחזור-בלבד` בקורפוס עם שתי שורות משניות בלבד,
והמסמך אומר זאת. **זו החלטה, לא פער פתוח.**

## 4 · המסלול — R-80

```yaml
route:
  - { action: smoke, trigger: { at_stage: start },      params: { pit_c: 110 } }
  - { action: wrap,  trigger: { at_core_temp: { c: 70 } }, params: { material: butcher_paper } }
  - { action: rest,  trigger: { when_safe_met: {} },    params: { min: 60 } }
```

הבעלים, 3.8.26: *"עטיפה ב-70°C היא פעולה שמופעלת בטמפרטורה, לא הערה. זו דרישה למנוע המסלולים."*

**חמישה סוגי טריגר סגורים** — מכסים את כל 390 המופעים שנמדדו:

| סוג | פרמטרים | מה שקיים היום | מופעים |
|---|---|---|---|
| `at_core_temp` | `c` | "עטיפה ב-65/70/75°C" | 46 |
| `after_elapsed` | `h` / `min` | "שיטת 3-2-1", "2-2-1" | 4 |
| `every` | `min` | "הפיכה", "סיבוב שיפוד", "הפיכת עור" | 34 |
| `at_stage` | `start` \| `end` \| `<שם שלב>` | "גלייז בסיום" | 12 |
| `when_safe_met` | — | **"עד סוף לבטיחות"** | 12 (משותף) |

**המנוע מעריך עץ; הנתונים כותבים עלה יחיד.**

```
evaluate(t, state):
  t.all_of → every(child → evaluate(child, state))
  t.any_of → some (child → evaluate(child, state))
  else     → PREDICATES[kind](t, state)
```

הקומבינטור הוא fold מעל אותה פונקציית פרדיקט — עלות של שורות ספורות. **‏0 מתוך 390 דורשים אותו היום**,
ולכן `all_of`/`any_of` הם **יכולת מנוע** ולא רשות-כתיבה, עד שמקרה אמיתי יידרש. **התנאי לגמישות הזו הוא
שער הנגישות (§7).**

## 9 · המעבר — הכרעת הבעלים: **הכל בבת אחת** ‏(3.8.26)

1. **סכימה + ולידטור** — הגדרה פורמלית, שנכשלת בבנייה.
2. **ממיר** 193 השורות השטוחות → המבנה החדש, אוטומטי היכן שאפשר.
3. **דוח אי-המרה** — הרשימה החשובה: כל `tgt` ללא מקור, כל `somid` שלא נפרס לטריגר, כל שדה שנשר.
   **אינו מושתק ואינו מנוחש.**
4. **שכבת קריאה (אדפטר)** — הקוד הקיים קורא דרכה; שום נתיב לא נשבר בבת אחת.
5. **הגירת צרכנים** — צרכן-צרכן, כל אחד עם בדיקותיו.
6. **השערים נדלקים** אחרי שהנתונים עברו.
