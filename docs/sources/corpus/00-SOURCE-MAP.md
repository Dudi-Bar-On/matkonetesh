### עמודת `extraction` — עכשיו העמודה החשובה ביותר

**נתונים עובדתיים אינם מוגנים בזכויות יוצרים; רק ביטוי יצירתי מוגן.** לכן הצורה החזקה היא **לחלץ את
המספרים** (טמפרטורות, זמנים, ppm, יחסים) **לטבלאות מובנות משלנו עם ייחוס מלא**, ולשמור לצדן את מסמך
המקור כעותק עיון. הערכים בעמודה:

| ערך | פירוש |
|---|---|
| `HTML` | טבלת HTML — פרסינג ישיר |
| `PDF‑T` | טבלה ב‑PDF — `WebFetch` → `pypdf` (הזרימה שאומתה ב‑§1) |
| `XML` / `CSV` / `API` | הזנה מובנית |
| `MANUAL` | המספרים קיימים אך פזורים בפרוזה — **תמלול ידני בלבד** |
| `✗` | אין מספרים לחלץ |

**רישיון — עכשיו אינפורמטיבי בלבד, לא שער.** ‏**שום מקור אינו מוחרג מההורדה מטעמי רישיון.**
`PD` = ממשל ארה"ב, נחלת הכלל · `EUR-Lex` = שימוש חוזר עם ייחוס · `©` = לשמור כעותק עיון, לחלץ את
**הנתונים** עם ייחוס.
