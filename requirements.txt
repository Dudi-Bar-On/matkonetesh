# Python dependencies for the build/tooling side of matconetesh.

# modules use only the standard library. This file exists for the agent-memory layer

#
# Python 3.14 is required, not merely supported: agent_memory stores metadata as SQLite
# JSONB, which needs SQLite >= 3.45.0. CPython pins SQLite per branch — 3.10 ships 3.37.2
# where jsonb() does not exist; 3.14 ships 3.50.4.

# Neo4j is a projection of it, and embeddings are produced by a local Ollama model so no document
# text leaves this machine.
#
# Declared here BEFORE the code that imports them exists, on purpose. check-requirements only sees

# three did it again a day later: CI could not even ask what constraint the Neo4j integration
