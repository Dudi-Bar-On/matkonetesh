# matconetesh — conventions

- **Hebrew-first RTL** is the primary UI language; English is secondary i18n coverage (see the
  assistant's own `i18n-english` memory for offline i18n mechanics). Any user-facing string change
  needs a Hebrew render check: no English leak, correct singular/plural on interpolated counts,
  correct domain term (not a generic mistranslation — L6: `תנור` was wrongly used as a generic device
  word once). Numeric/math readouts need `dir="ltr"` islands — bidi can flip `≥` into `≤` visually
  even though the DOM text is correct (L13).
- **Safety values trace to primary sources.** Any `safe` temperature, `bcheck` stage value, or cook
  duration must trace to a citation in `sources.py` / `docs/sources/baldwin-backbone.md` (USDA/FSIS,
  Baldwin, 9 CFR — never a blog, never guessed). The 279 citations are merged into data at build time,
  so grepping `data.py` alone will not show them.
- **Secrets never enter the repo.** Gemini and Cloudflare keys live ONLY as Cloudflare Worker secrets.
  Never echo, commit, or paste one into any report or memory.
- **Build-artifact boundary**: `index.html` (root) and everything under `dist/` are generated by
  `python build.py` and gitignored. Treat them as read-only outputs; the editable sources are
  `app.js`, `app.css`, and the Python data layer.
- **Version stamp**: `מהדורה NNN · D.M.YY`, rendered in `.foot-stamp`. A push is not a release —
  Cloudflare Pages rebuild takes minutes; CLAUDE.md §10.10 requires a live Playwright check (stamp +
  a feature probe) before a version is reported as shipped.
